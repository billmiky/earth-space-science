Using this timeline

  • Tap any card to open it. The popup shows the card's own text, the bigger story, and how it connects to other cards. Older / Newer (or swipe) moves through time.
  • All cards: the finished timeline. Build it: add cards one at a time, oldest first, so the class can predict where the next one goes. Connections: step through sample arrows from the packet's student work (red = causes, blue dashed = increasing complexity).
  • Stretched makes the last billion years 7× wider so the crowded cards fit. Switch to True scale to show how recent complex life really is. Each card has a line to its exact date on the axis.

Keyboard (or clicker)

→ / ← next or previous step (or card, when a popup is open) · Enter open the current step's card · Esc close · F full screen · 1 2 3 switch modes

Placement and corrections

Card placement follows the Coevolution teacher guide's answer key. A few cards differ from current science (for example, the Rodinia card's date and the "first plants" wording on the algae card). Each one has a Teacher note in its popup.
