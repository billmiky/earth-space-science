27 Anchor Phenomenon

27.1 🌀 It Has Felt Like Storms Are Getting Worse

Does the data support that feeling, and will it continue?

In recent years, powerful storms have battered communities across the United States. From deadly blizzards burying the Northeast under feet of snow to Category 5 hurricanes devastating coastal cities, it feels like extreme weather is getting worse. But science doesn’t run on feelings—it runs on evidence.

In this unit, you will investigate whether storms really are becoming more frequent and intense, and use climate models to argue what the future may hold for your community.

28 Unit Driving Question

28.0.1 Will there be more frequent and more intense severe storms in the future?

This question will guide your work across all four lesson sequences in this unit. By the end, you will construct an evidence-based argument about how climate change may alter storm patterns in your region.

32.1 🌥️ Global Cloud Cover by Season

Where the atmosphere is most active, you see clouds. Three patterns drive almost everything in this unit: the Intertropical Convergence Zone (ITCZ), mid-latitude storm tracks (where blizzards live), and monsoon systems. All three shift with the seasons — and that shift is exactly why hurricane season and blizzard season fall when they do.

  // ── Cloud fraction model (lat-row base + fast pixel corrections) ──────────

  function cfRowBase(lat, S) {
    var b = 0.50;
    var itczLat = { DJF: -5, MAM: 4, JJA: 10, SON: 3 }[S];
    b += 0.40 * Math.exp(-0.5 * Math.pow((lat - itczLat) / 9,  2));
    var nhLat  = { DJF: 56, MAM: 52, JJA: 57, SON: 54 }[S];
    var nhStrg = { DJF: 0.27, MAM: 0.20, JJA: 0.11, SON: 0.22 }[S];
    b += nhStrg * Math.exp(-0.5 * Math.pow((lat - nhLat) / 11, 2));
    b += 0.24   * Math.exp(-0.5 * Math.pow((lat + 52)   / 10, 2)); // Southern Ocean
    var nhSub = { DJF: 25, MAM: 27, JJA: 30, SON: 27 }[S];
    b -= 0.20   * Math.exp(-0.5 * Math.pow((lat - nhSub) / 8,  2)); // NH subtropical dry
    b -= 0.17   * Math.exp(-0.5 * Math.pow((lat + 25)   / 8,  2)); // SH subtropical dry
    if (S === 'DJF' && lat > 65) b -= 0.10; // Arctic winter dry
    if (lat < -75)               b -= 0.10; // Antarctic plateau
    return b;
  }

  function cfPixel(lat, lng, S, base) {
    var cf = base;
    if (lat >  12 && lat <  35 && lng >  -10 && lng <  58)  cf -= 0.22; // Sahara / Arabian

    if (S === 'JJA' && lat > 20 && lat <  40 && lng >  110 && lng <  145) cf += 0.17; // E Asian Meiyu
    if (S === 'SON' && lat >  0 && lat <  20 && lng >   65 && lng <  115) cf += 0.18; // monsoon retreat

    if (S === 'JJA' && lat > 25 && lat < 42 && lng > -130 && lng < -120) cf += 0.18; // CA marine stratus

    if (lat > -28 && lat < -10 && lng >    7 && lng <   18)  cf += 0.17; // Benguela stratus
    if ((S === 'DJF' || S === 'SON') && lat > 40 && lat < 65 && lng > -50 && lng < -10) cf += 0.10; // N Atlantic belt

  }

  function drawGeo(ctx, W, H, feature) {
    var geom = (feature && feature.geometry !== undefined) ? feature.geometry : feature;
    if (!geom) return;
    function rings(poly) {
      poly.forEach(function (ring) {
        ring.forEach(function (pt, i) {
          var x = ((pt[0] + 180) / 360) * W;
          var y = ((90 - pt[1]) / 180) * H;
          if (i === 0) ctx.moveTo(x, y); else ctx.lineTo(x, y);
        });
        ctx.closePath();
      });
    }
    if      (geom.type === 'MultiPolygon')    geom.coordinates.forEach(rings);
    else if (geom.type === 'Polygon')         rings(geom.coordinates);
    else if (geom.type === 'GeometryCollection') geom.geometries.forEach(function (g) { drawGeo(ctx, W, H, { geometry: g }); });
    else if (feature.type === 'FeatureCollection') feature.features.forEach(function (f) { drawGeo(ctx, W, H, f); });
  }
